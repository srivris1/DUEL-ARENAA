# VALTREAK 🎮

Hey everyone! Welcome to **VALTREAK**, a browser-based mini multiplayer game arena I built. 

## What is this?
I created this project to tackle a problem statement requiring a web-based multiplayer game with a modern frontend stack. Instead of just picking one game, I went ahead and built a mini-arena featuring three classic games:
- ❌⭕ **Tic-Tac-Toe**
- 🔴🟡 **Connect Four**
- ✂️🪨 **Rock Paper Scissors**

## Features & Requirements Met
- **Playable Games**: Three fully functional games with clear rules and accurate win/draw logic.
- **Multiplayer Mode**: Two players can play against each other. You can host a room and share a 5-letter code to let a friend join from anywhere, directly in their browser.
- **Turn-based Logic**: The app properly handles player turns and prevents illegal moves.
- **Game State & UI**: Real-time display of the current game state, scores, and winner announcements.
- **Restart Options**: Easily move to the next round or reset the match completely without reloading.
- **Responsive Design**: A sleek, engaging, and responsive UI with a built-in dark/light mode toggle.

## Tech Stack & Skills Showcased
- **Frontend**: React, TypeScript, and Vite for a blazingly fast modern UI.
- **Styling**: Tailwind CSS combined with Framer Motion for buttery smooth animations.
- **State Management**: Complex game logic and state handled carefully via custom React hooks and reducers.
- **Real-time Communication**: PeerJS (WebRTC) is used under the hood to handle peer-to-peer real-time communication between players without needing a dedicated backend game server!
